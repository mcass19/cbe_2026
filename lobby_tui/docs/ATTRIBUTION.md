# Sprite attribution

The placeholder avatar sprites in `priv/sprites_src/` are original work created for this repository by the `gen_placeholder_sprites.exs` script (`priv/scripts/gen_placeholder_sprites.exs`). Each is a simple 12x12 solid-color creature with a two-pixel eye row and is released into the public domain under CC0.

Community PRs replacing or adding sprites should append a row to the table below, listing the true source and license of each new file. Any addition whose license is not CC0/public-domain-equivalent or is not clearly compatible with this project's license needs a note explaining why it is acceptable.
